# Source Registry

Authoritative and discovery sources used by the project are recorded with publisher, locator, publication/revision date when available, access date, scope, and the claims they support. Empty or planned source collections must not be presented as evidence.

The [scoped non-format claim audit](nonformat-claim-audit.md) maps CNC context,
tooling compatibility, additive emissions and laser hazard categories to primary
sources. It distinguishes those facts from repository policies and synthetic
fixture values; it is not a complete public-alpha or regulatory audit.
