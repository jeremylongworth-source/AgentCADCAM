# Pilot Packet Template

Copy this directory for one consented, sanitized pilot evaluation. Keep raw input separate from baseline output, skill output, reviewer findings, edits, safety findings, and final verdict.

The required packet layout mirrors Phase 8 of `ROADMAP.md`. Record the final decision in `final-verdict/final-verdict.yaml` after the reviewer has completed the packet.

Do not place confidential CAD, proprietary NC/G-code, credentials, private machine endpoints, or export-sensitive data in the repository.
