# Safety Governance Standard

Safety is a hard gate. It is never averaged into a quality score. Any unresolved machine, controller, setup, workholding, tooling, postprocessor, material, environmental, simulation, authorization, or human-approval condition that could affect safe manufacturing must remain blocking.

The system must never control a physical machine or bypass safeguards. Execution-adjacent outputs default to `REVIEW_REQUIRED` and must include assumptions, evidence, verification, and human approval scope. A generated artifact is not self-authorizing.
