# Interoperability Standard

Every exchange plan must identify the authoritative source, target workflow, selected format, units, revision, semantics preserved, semantics likely lost, transformation path, and verification required.

Meshes are geometry derivatives, not automatically complete product definitions. A successful file import does not prove that PMI, tolerances, materials, revisions, or design intent survived. Interoperability findings must distinguish parseability, geometric fidelity, semantic fidelity, and manufacturing readiness.
